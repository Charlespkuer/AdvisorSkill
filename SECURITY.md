# Reporting privacy and security issues

Provide a minimal synthetic reproduction. Avoid putting private comments, unpublished manuscripts, paths, names, credentials, or unredacted task packets in public issues. For a sensitive issue, contact the project maintainers privately before publishing details.

The CLI reads local files. Workspaces and generated artifacts rely on the user's OS permissions and storage configuration. Keep the workspace private and review which data your host agent receives before it reads a task packet.
